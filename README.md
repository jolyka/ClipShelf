# ClipShelf

Небольшой нативный менеджер буфера обмена для macOS. Хранит последние тексты и изображения, автоматически подхватывает обычные скриншоты и сразу кладёт новый снимок в буфер — после `⇧⌘4` можно сразу нажимать `⌘V`.

Работает в строке меню, не требует регистрации, не использует сторонние библиотеки и ничего не отправляет в интернет.

## Что умеет

- хранит до 30 последних текстов и изображений;
- автоматически добавляет обычные скриншоты `⇧⌘3`, `⇧⌘4` и `⇧⌘5`;
- реагирует на событие создания файла без искусственной задержки;
- сразу помещает последний скриншот в системный буфер обмена;
- сохраняет снимки, сделанные напрямую в буфер через `⌃⇧⌘3/4/5`;
- показывает историю по глобальной комбинации `⌃⌥⌘C`;
- очищает историю по комбинации `⌃⌥⌘⌫`;
- позволяет менять обе комбинации в настройках;
- возвращает любую запись в буфер обычным кликом;
- пропускает скрытые и временные записи менеджеров паролей;
- хранит данные только локально.

## Системные требования

- macOS 14 Sonoma или новее;
- Mac с Apple Silicon или Intel.

Готовая сборка универсальная и содержит обе архитектуры: `arm64` и `x86_64`.

## Быстрая установка

1. Откройте раздел [Releases](https://github.com/jolyka/ClipShelf/releases/latest).
2. Скачайте `ClipShelf-macOS.zip`.
3. Распакуйте архив.
4. Перетащите `ClipShelf.app` в папку «Программы» (`Applications`).
5. Первый раз откройте приложение правой кнопкой мыши → «Открыть» → «Открыть».

После запуска ClipShelf появится в правой части строки меню. Значка в Dock у приложения нет — это нормально.

Если macOS всё равно блокирует запуск, откройте:

> Системные настройки → Конфиденциальность и безопасность → Всё равно открыть

Если появится запрос на доступ к Рабочему столу или другой папке скриншотов, разрешите доступ: без него ClipShelf не сможет увидеть созданный файл.

## Как пользоваться

### Скриншоты

1. Нажмите `⇧⌘4`.
2. Выделите область экрана.
3. Сразу вставляйте снимок через `⌘V` в Telegram, браузер, редактор или другое приложение.

ClipShelf сохранит снимок в истории и одновременно сделает его текущим содержимым буфера обмена.

### Текст

Скопируйте текст обычным `⌘C`. Он автоматически появится в истории. Клик по карточке вернёт текст в буфер без изменения пробелов и переносов строк.

### История

- `⌃⌥⌘C` — показать или открыть историю;
- `⌃⌥⌘⌫` — очистить историю;
- клик по карточке — скопировать запись;
- кнопка корзины на карточке — удалить одну запись;
- кнопка корзины в заголовке — очистить всё.

Горячие клавиши можно поменять через кнопку настроек в панели ClipShelf.

## Важно: плавающая миниатюра macOS

ClipShelf отключает системную плавающую миниатюру скриншота в правом нижнем углу. Это нужно, чтобы macOS сразу завершала запись файла и снимок без ожидания попадал в буфер обмена.

Чтобы вернуть миниатюру:

1. Завершите ClipShelf через правый клик по значку в строке меню.
2. Выполните в Терминале:

```sh
defaults write com.apple.screencapture show-thumbnail -bool true
```

При следующем запуске ClipShelf снова отключит миниатюру.

## Где хранятся данные

История находится здесь:

```text
~/Library/Application Support/ClipShelf/
```

Тексты записываются в локальный JSON-индекс, изображения — в PNG. Максимум хранится 30 записей; старые удаляются автоматически. Сетевых запросов в приложении нет.

## Сборка из исходников

Потребуются macOS 14+, Swift 6 и Xcode Command Line Tools:

```sh
xcode-select --install
git clone https://github.com/jolyka/ClipShelf.git
cd ClipShelf
chmod +x scripts/build-app.sh
./scripts/build-app.sh
```

Скрипт отдельно собирает версии для Apple Silicon и Intel, объединяет их в Universal Binary, создаёт `.app`, подписывает его локальной ad-hoc подписью и формирует ZIP.

Результат появится в папке `outputs`:

```text
outputs/ClipShelf.app
outputs/ClipShelf-macOS.zip
```

Проверить архитектуры можно командой:

```sh
lipo -info outputs/ClipShelf.app/Contents/MacOS/ClipShelf
```

## Если что-то не работает

### Приложение «не открывается»

ClipShelf может уже работать без окна. Найдите его значок справа в строке меню или нажмите `⌃⌥⌘C`. Повторный запуск приложения также открывает панель.

### Скриншот не появляется

- убедитесь, что ClipShelf запущен;
- проверьте доступ приложения к Рабочему столу в настройках конфиденциальности macOS;
- если папка сохранения скриншотов изменена, убедитесь, что она существует и доступна;
- сделайте новый снимок: уже существующие файлы намеренно не импортируются при запуске.

### `⌘V` вставляет предыдущий объект

Проверьте, отключена ли плавающая миниатюра:

```sh
defaults read com.apple.screencapture show-thumbnail
```

Значение `0` означает, что она отключена.

## Приватность

- история хранится только на Mac;
- приложение не содержит аналитики и сетевого кода;
- скрытые и временные записи буфера не сохраняются;
- историю можно очистить из интерфейса или сочетанием клавиш.

Перед использованием на рабочем компьютере учитывайте, что обычный скопированный текст сохраняется локально в истории до удаления или вытеснения более новыми записями.
